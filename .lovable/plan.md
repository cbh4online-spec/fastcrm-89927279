

# Fix: Lead items in AI chat linking to list instead of detail page

## Root Cause

The `ask-fastcrm` edge function generates lead items with `link: "/dashboard/leads"` (the general list) instead of `link: "/dashboard/leads/${l.id}"` (the specific lead detail page). This is why clicking on "Jorge", "Tomas", "Joaquim Bica", etc. in the AI chat panel opens the full list of 551 leads.

The frontend navigation code is correct — `onItemClick={(item) => navigate(item.link)}` — the problem is entirely in the link value generated by the backend.

## Fix

**File: `supabase/functions/ask-fastcrm/index.ts`**

**Line 2565** — Stale leads in priorities handler:
- Change: `link: \`/dashboard/leads\``
- To: `link: \`/dashboard/leads/${l.id}\``

This is the only place where individual lead items are pushed with incorrect links. The other `/dashboard/leads` references (lines 2600, 2733, 2746) are for aggregate "View all leads" actions, which correctly link to the list.
