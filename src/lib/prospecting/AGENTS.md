# Prospecting rules

- Present Instagram extraction job state only via `src/lib/prospecting/extractionJobState.ts` (error beats completed, unsupported sources always fail, stale running jobs stop polling); unsupported sources mirror `_shared/instagramSources.ts` and are blocked in start and worker before any provider call.
- Instagram followers/following come only from the Apify Actor adapter `_shared/instagramApifyRelationships.ts` (project Apify connection via gateway, async run + dataset offset persisted in `next_cursor`, cost cap via maxItems/maxTotalChargeUsd) or, as fallback, the ProfileQuery adapter `_shared/instagramRelationships.ts`; jobs without one of these `provider` values are legacy instagram-looter2 and always fail without provider calls, so sources are never silently substituted and runs are never started twice.
